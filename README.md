## Tasks Covered

1. Create a directory using `mkdir`
2. Create a file using `touch`
3. Rename a file using `mv`
4. View file contents using `cat`
5. View first lines using `head`
6. View last lines using `tail`
7. Search text using `grep`
8. Zip a directory using `zip`
9. Unzip a file using `unzip`
10. Download a file using `wget`
11. Change file permissions using `chmod`
12. Set an environment variable using `export`
